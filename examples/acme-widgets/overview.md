# Acme Widgets

Acme Widgets is a catalog API for managing widgets and their variants. A widget is a
product; a variant is a specific size and color combination of that widget.

## Concepts

- **Widget**: a catalog entry with a name and description.
- **Variant**: a purchasable version of a widget (size, color, price).
- **Sandbox**: a free test environment with lower quotas.

See [Quotas](guide/quotas.md) for limits and the [FAQ](faq.md) for common questions.
